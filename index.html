Features

Every tool a researcher needs

Noteration was built around one idea: the research workflow shouldn't be fragmented across five different apps. Notes, papers, citations, and version control — all in one place.

✎
Markdown Editor

Full syntax highlighting, line numbers, auto-indent, and an instant preview mode. Write in raw Markdown or render to HTML with one keypress.

Ctrl+Shift+V
🧘
Focus Mode

Press F11 for fullscreen, distraction-free writing. The editor centers itself, all UI hides, and Vim keybindings activate for keyboard-only flow.

New in v1.1
🕸️
Wiki-links & Graph

[[note-name]] links between notes with Ctrl+Click navigation. An interactive force-directed graph visualises your entire knowledge network.

NetworkX
📘
PDF Viewer

Read PDFs without leaving the app. Highlight text, add sticky notes, and capture image regions — all stored in non-destructive JSON, synced via Git.

PyMuPDF
📚
Literature Browser

Browse your Papis library. Fetch metadata automatically from DOI, arXiv, or ISBN. Export to BibTeX per-note or for the entire library.

Papis
🔍
Global Search

One search bar covering all notes, literature metadata, and PDF annotation content simultaneously. Supports regex and case-sensitive filters.

Vault-wide
☁️
Git Sync

Auto-commit, pull, and push to any remote. Three merge strategies — rebase, merge, stash. A visual three-panel conflict resolution dialog is built in.

GitPython
🎨
Dark / Light / System

Full theme engine with light, dark, and OS-adaptive modes. Changes apply live in Settings — press Cancel to revert instantly.

PySide6
📖
Research Guide

Press F2 for an in-app briefing on academic writing strategies — from critical reading techniques to documentation systems and argumentation.

New in v1.1
How It Works

The vault-centric research loop

Everything lives in a single folder — your Vault. It's portable, version-controlled, and readable without Noteration.

01
Create or open a Vault

A Vault is just a directory. Noteration adds .noteration/config.toml, then you populate notes/, literature/, and attachments/.

02
Read, highlight, and annotate PDFs

Open any paper. Highlight passages, add margin notes — none of it touches the original PDF. Annotations are stored as portable JSON.

03
Write with wiki-links and citations

In your Markdown note, type [[ to link another note, or @ to autocomplete a citation key from your Papis library.

04
Sync to GitHub

One click — or auto every 5 minutes. Noteration commits, pulls, and pushes. Your vault is backed up and accessible on any device.

~/research-vault/
├── .noteration/     ├── config.toml # your settings     └── link_graph.json # backlink cache   ├── notes/ # Markdown files     ├── index.md     ├── methodology.md     └── results/         └── chapter-3.md   ├── literature/ # Papis library     └── creswell2014/         ├── info.yaml         └── creswell2014.pdf   ├── annotations/ # JSON, synced ✓     └── <sha256>.json   └── attachments/ # images, files     └── diagram.png   ✓ git remote: github.com/you/vault ✓ auto-sync every 5 min
Installation

Up and running in under a minute

Choose your platform. Each one-liner creates a virtual environment, installs all dependencies, and adds a desktop shortcut.

🐧
Linux
curl -fsSL https://raw.githubusercontent.com/lilamr/noteration/main/install.sh | bash

Creates a .desktop entry in your applications menu. Requires Python 3.11+, Git, and python3-venv.

🍎
macOS
curl -fsSL https://raw.githubusercontent.com/lilamr/noteration/main/install.sh | bash

Creates Noteration.app in ~/Applications with a proper icon — visible in Launchpad.

🪟
Windows
irm https://raw.githubusercontent.com/lilamr/noteration/main/install.ps1 | iex

Run in PowerShell. Creates a Desktop shortcut and a Start Menu entry. No admin rights required.

Manual / Development
# Clone and install for development $ git clone https://github.com/lilamr/noteration.git $ cd noteration $ pip install -e ".[all]" $ python -m noteration
